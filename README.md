# AI Code Generation and Evaluation Using Python

**Register Number:** URK23CS1273

## Overview
This folder contains five simplified Python demonstrations covering natural-number generation, a GAN-style code-generation concept, code-completion examples, and basic code-quality evaluation.

## Programs
1. `1b_code_generation.py` — Generates numbers from 0 to n and checks multiple test cases.
2. `2_gan_style_demo.py` — Prints sample real and generated code as a simplified GAN-style demonstration.
3. `4_code_completion_demo.py` — Demonstrates completion of a partially written average function.
4. `5_code_completion_examples.py` — Demonstrates simple factorial and string-reversal code completion.
5. `6_code_quality_evaluation.py` — Performs AST syntax checking, execution checking, test-case validation, and a simple quality score.

## Run
Open this folder in VS Code and run each file, or use:

```bash
python 1b_code_generation.py
python 2_gan_style_demo.py
python 4_code_completion_demo.py
python 5_code_completion_examples.py
python 6_code_quality_evaluation.py
```

## Important note
These are simplified demonstrations using ordinary Python. They do **not** implement a trained GAN, GPT-2/Transformer model, or an actual AI code generator. The GAN-style and code-completion files illustrate the concepts with fixed examples. The quality evaluator demonstrates AST, execution, and test checks; it does not invoke Pylint, Mypy, or Pytest.
